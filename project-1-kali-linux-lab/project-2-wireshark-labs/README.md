# Project 2: Wireshark Network Traffic Analysis

## Objective
Practice network traffic analysis and investigate common network activities using Wireshark.

## Labs Completed

### Lab 1: Identify the Attacker's IP
Practiced inspecting network packets to identify a suspicious IP address.

### Lab 2: Follow TCP Stream
Explored TCP conversations and examined the contents of network communication.

### Lab 3: Follow TCP Stream, Part 2
Investigated HTTP traffic and examined web page requests and responses.

### Lab 4: HTTP Plain Text Credentials
Studied HTTP traffic and how credentials may be exposed when transmitted without encryption.

### Lab 5: Catch the Brute Force Attacker
Investigated FTP login attempts, response codes, and repeated authentication attempts.

### Lab 6: Catch the Call Scammer
Examined VoIP traffic, including SIP call signaling and RTP voice traffic.

## Tools and Concepts
- Wireshark
- Packet inspection and display filters
- IP addresses and TCP streams
- HTTP and FTP
- Failed and successful login response codes
- SIP and RTP

## Learning Outcomes
- Practiced inspecting captured network traffic.
- Learned how to follow TCP conversations.
- Investigated repeated login attempts and FTP response codes.
- Distinguished call signaling from voice transport protocols.
- Improved practical network troubleshooting and traffic analysis skills.
