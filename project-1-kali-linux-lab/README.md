# Project 1: Kali Linux Lab Setup

## Objective
Set up a virtual cybersecurity lab using Kali Linux and VirtualBox on an Ubuntu host.

## Environment
- **Host Operating System:** Ubuntu Linux
- **Virtualization Platform:** Oracle VirtualBox
- **Guest Operating System:** Kali Linux 2026.2
- **Virtual Machine Memory:** 4 GB RAM
- **Processors:** 2 CPU cores
- **Networking:** VirtualBox NAT Network

## Configuration and Tasks
- Imported and configured the Kali Linux virtual machine.
- Configured the virtual network interface.
- Verified internet connectivity using ping.
- Configured and tested the shared folder.
- Enabled bidirectional clipboard and drag-and-drop.
- Created a snapshot named `Clean Lab Setup`.

## Validation
- Kali Linux successfully booted in VirtualBox.
- Internet connectivity was verified.
- Shared-folder access was tested.
- A clean snapshot was created for restoring the lab environment.
